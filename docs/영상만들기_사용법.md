# 찬찬이 영상 만들기 — 사용법 (MD 한 파일로 영상 양산)

**`점포_영상콘텐츠.md` 한 파일만 편집하면** 점포 소개·이벤트·교육 등 다양한 영상이 만들어집니다.

---

## 가장 쉬운 방법 (원클릭)

`영상만들기.command` 파일을 **더블클릭** → 음성 생성부터 영상 렌더까지 자동 실행.
완성 영상은 `my-video/out/` 폴더에 저장됩니다.

> 터미널에서: `cd 점포안내영상_자동화 && ./영상만들기.command`

---

## MD 작성법

`## 제목` 하나 = **영상 1편**입니다. 아래 형식으로 쓰세요.

```markdown
## 광화문점 독서의 달 스탬프 투어        ← 영상 제목 (아웃트로에 표시)
- 점포: 001                            ← 점포번호(001~028). 캐릭터 의상 결정 (필수)
- 유형: 이벤트                          ← 소개 / 이벤트 / 교육 / 안내 (인트로 배지)
- 기간: 2026.06.01 ~ 06.30             ← 그 외 자유 항목 → 아웃트로에 표시
- 장소: 1층 이벤트 존
- 느루: appear                         ← appear(등장)/hat(모자)/roll(구르기), 생략 가능
### 내용
조금 느려도 괜찮아요, 찬찬이예요.          ← 한 줄 = 자막 1줄 = 음성 1문장 (12~40자)
6월 한 달, 독서의 달 스탬프 투어가 열려요.
책을 읽고 스탬프를 모아보세요.
...
```

### 규칙 요약
| 항목 | 설명 |
| --- | --- |
| `## 제목` | 영상 1편 시작. 제목은 아웃트로에 큰 글씨로 표시 |
| `- 점포:` | **필수.** 001~028 → 해당 점포 캐릭터(의상) 사용 |
| `- 유형:` | 인트로 배지 텍스트 (소개·이벤트·교육·안내 등 자유) |
| `- 느루:` | appear / hat / roll (생략 시 점포 기본값) |
| `- 그 외 키:값` | 운영시간·오시는길·기간·장소·대상·문의 등 → 아웃트로 정보로 자동 표시 |
| `### 내용` 아래 줄 | 각 줄이 자막 1개 + 음성 1문장. 빈 줄/`---`는 무시 |
| 제목에 `비활성` | 그 영상은 렌더에서 제외 |

## 새 영상 추가 예시

MD 맨 아래에 이렇게 한 블록만 추가하면 끝:

```markdown
## 강남점 여름 독서 챌린지
- 점포: 011
- 유형: 이벤트
- 기간: 2026.08.01 ~ 08.31
- 대상: 전 연령 누구나
### 내용
안녕하세요, 강남점 찬찬이예요.
여름 독서 챌린지가 시작됐어요.
하루 30분, 함께 책을 읽어요.
완주하면 특별 배지를 드려요.
지하 1층에서 신청하세요.
느루와 함께 응원할게요!
```

저장 후 `영상만들기.command` 실행 → 새 영상이 추가로 렌더됩니다.

## 수동 실행 (단계별)
```bash
cd 점포안내영상_자동화
python3 build_from_md.py            # MD → 음성 + 데이터
# 특정 MD: python3 build_from_md.py --md 다른파일.md

cd ../my-video
npm run dev                         # Studio에서 미리보기 (선택)
npm run render-all                  # 전체 렌더
node render-all.mjs v001 v029       # 특정 영상만 (id는 빌드 로그에 표시)
```

## 영상 사양 / 운영 전환
- 1080×1920 세로 · 30fps · 편당 약 24~33초
- 인트로(유형 배지 + 찬찬이 + 슬로건) → 본문(캐릭터 + 자막) → 아웃트로(제목 + 정보 + 맺음말)
- **음성**: 현재 데모용 macOS `say`(Yuna). 실제 운영은 `build_from_md.py`의 음성 부분을
  **Clova Voice** 호출로 교체하면 동일 흐름으로 고품질 음성 적용 (타이밍 자동 재계산)
- **캐릭터 움직임**: 정지 누끼 PNG + 플로팅. Veo/Kling AI 클립(mp4)으로 교체 시
  `StoreVideo.tsx`의 `<Img>`를 `<Video>`로 변경
```
