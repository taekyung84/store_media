# 점포 영상 제작 자동화 — 로컬 웹앱 사용법

브라우저 폼에서 **선택·입력만 하면** 음성·자막·캐릭터 영상이 자동 생성됩니다. 코드 지식 불필요.

---

## 실행
- **가장 쉬움**: `영상제작_웹앱.command` 더블클릭 → 브라우저 자동 오픈
- 터미널: `cd 점포안내영상_자동화 && python3 server.py` → `http://localhost:8765`

---

## 입력 항목
| 항목 | 설명 |
| --- | --- |
| **점포** | 001~028 선택 (제목·정보·파일명에 반영) |
| **유형** | 이벤트 / 공지 / 교육 → 인트로 배지로 표시 |
| **제목** | 아웃트로에 크게 표시 |
| **아웃트로 정보** | 항목명/내용 3줄 (예: 기간·장소·대상). 빈 칸은 표시 안 됨 |
| **내용(내레이션)** | 한 줄 = 자막 1개 = 음성 1문장 |

## 커스터마이징
| 항목 | 옵션 |
| --- | --- |
| **목소리** | 여성 / 남성 / 여아 / 남아 (무료 edge-tts 고품질 한국어) |
| **캐릭터** | 기본 찬찬이(메인) / 점포 특색 캐릭터(의상) |
| **배경 테마** | 연두 · 주황 · 하늘 · 베이지 · 분홍 |
| **AI 캐릭터 움직임** | 동작 선택: 기본(생동감)·인사·댄스·걷기·두리번·통통·없음 |

## 추천 콘텐츠
**📝 추천 내용 불러오기** 버튼 → 선택한 점포·유형에 맞는 제목·정보·내레이션이 자동으로 채워집니다.
(점포의 실제 운영시간·오시는길·이벤트 정보를 활용) 채워진 내용은 자유롭게 수정 가능.

## 제작
**🎬 영상 만들기** → 약 1분 후 오른쪽에 영상 표시 + 다운로드.
저장 파일명: **`점포명_날짜시간_길이s.mp4`** (예: `광화문점_2606271900_21s.mp4`)
→ `점포명_YYMMDDHHmm_길이(초)s`. 실제 파일은 `my-video/out/` 에도 저장됩니다.

---

## 목소리 (무료 TTS)
- 엔진: **Microsoft edge-tts** (API 키 불필요, 인터넷 연결 필요, 고품질 신경망 음성)
- 여성=SunHi · 남성=InJoon · 여아/남아=피치 조정으로 아이 목소리 구현
- 인터넷이 안 되면 자동으로 macOS 내장 음성(Yuna)으로 폴백

## AI 캐릭터 움직임 (현재 / 향후)
- **현재(무료·즉시)**: 동작을 선택하면 캐릭터가 그에 맞게 움직입니다 (별도 비용/계정 없이 바로 동작).
  - **기본**: 둥실+호흡 (잔잔한 생동감) · **인사**: 까딱이며 인사 · **댄스**: 바운스+좌우 스텝
  - **걷기**: 좌우로 걸어다님 · **두리번**: 좌우로 두리번 · **통통**: 제자리 점프 · **없음**: 정지
  - 동작은 본문 구간에 적용되며, 인트로는 인사·아웃트로는 기본 모션이 자동 사용됩니다.
- **향후(진짜 AI 영상생성)**: Veo·Kling·RunComfy 같은 image-to-video는 **외부 계정/API 키**가 필요합니다.
  키가 준비되면 `stickers_cutout`의 캐릭터로 움직이는 클립을 생성해 정지 이미지 대신 사용하도록 연결할 수 있습니다.
  (설치된 `image-to-video` 스킬 활용)

## 캐릭터 이미지 교체 (누끼 직접 교체)
캐릭터의 **원본 폴더는 `my-video/public/characters/`** 입니다. 여기 파일을 **같은 이름으로 덮어쓰면** 바로 반영됩니다. (스크립트는 파일이 있으면 그대로 쓰고, 없을 때만 자동 생성 → 교체본이 보존됨)

| 파일명 | 캐릭터 |
| --- | --- |
| `char_main.png` | 메인 찬찬이 (웹앱 기본) |
| `char_001.png` ~ `char_028.png` | 점포 특색 캐릭터 |

- 조건: **PNG + 투명 배경**, 캐릭터에 맞게 여백 잘라서(크기·위치 일관), 비율 자유
- 폴더 안 `_캐릭터_교체방법.txt` 에 전체 파일명↔점포 매핑이 있습니다
- 교체 후 영상을 다시 만들면 새 이미지로 렌더됩니다

## 세 가지 제작 방식
| 방식 | 적합 | 실행 |
| --- | --- | --- |
| **웹앱** (이 문서) | 담당자가 즉석에서 1편씩 | `영상제작_웹앱.command` |
| **MD 일괄** | 여러 편 양산 | `점포_영상콘텐츠.md` → `영상만들기.command` |
| **Remotion Studio** | 디자인 직접 미세조정 | `cd my-video && npm run dev` |

## 사내 공유 (선택)
`server.py`의 `127.0.0.1`을 `0.0.0.0`으로 바꾸면 같은 네트워크의 다른 PC에서
`http://<이 PC IP>:8765` 로 접속 가능 (보안 검토 후 사용).
